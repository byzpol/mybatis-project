```
$ curl -sS --noproxy '*' -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:5173/

$ netstat -ano | grep 5173
  TCP    [::1]:5173             [::]:0                 LISTENING       32936
```

### 2.2 ⚠️ 本机 `http_proxy` 会拦 localhost 请求

```
$ env | grep -i proxy
https_proxy=http://127.0.0.1:49856
HTTPS_PROXY=http://127.0.0.1:49856
HTTP_PROXY=http://127.0.0.1:49856
http_proxy=http://127.0.0.1:49856
```

不绕过代理时 `curl http://127.0.0.1:5173/` 返回 **HTTP 502**（代理接管的假错）。
所有本机探测都必须带 `curl --noproxy '*'`。

## 5. ⚠️ 施工事故：起错了 Tomcat（CATALINA_HOME 指向 11）

### 5.1 现象：`/cms-mis/*` 一律 404，`tomcat9/logs` 恒空

```
$ ls -la "$TC/logs/"      # $TC = D:/develop/jdk/tomcat9/apache-tomcat-9.0.122
total 8
drwxr-xr-x 1 admin 197609 0 Sep 10 06:55 .
drwxr-xr-x 1 admin 197609 0 Sep 10 06:55 ..
```

### 5.2 根因：启动日志里的 CATALINA_HOME 是 Tomcat 11

```
$ env | grep -i "^CATALINA"
CATALINA_HOME=D:\develop\jdk\apache-tomcat-11.0.18-windows-x64\apache-tomcat-11.0.18
```

启动日志（节选）——注意引擎版本与 webapps 路径都不是 tomcat9：

```
开始初始化 Servlet 引擎:[Apache Tomcat/11.0.18]
正在部署web应用程序存档文件[D:\develop\jdk\apache-tomcat-11.0.18-windows-x64\
    apache-tomcat-11.0.18\webapps\ROOT.war]
把web 应用程序部署到目录 [D:\develop\jdk\apache-tomcat-11.0.18-windows-x64\
    apache-tomcat-11.0.18\webapps\docs]
把web 应用程序部署到目录 [...\webapps\OnlineExamSystem_war]
```

### 5.3 修法：启动前显式覆盖

```bash
export CATALINA_HOME="D:/develop/jdk/tomcat9/apache-tomcat-9.0.122"
export CATALINA_BASE="$CATALINA_HOME"
cd "$CATALINA_HOME" && cmd //c "bin\\catalina.bat run"
```

